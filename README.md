# Python and DSA Practice

This repository contains my Python practice, Data Structures and Algorithms (DSA) practice, and assessment work.

## Folder Structure

- `python-practice/` — Python concepts and coding practice in Jupyter notebooks.
- `dsa/` — DSA concepts and problem-solving practice in Jupyter notebooks.
- `assessment/` — Assessment solution in Python.

## Git Workflow

Work is organized using separate branches for Python practice, DSA practice, and assessment work. Changes are committed with descriptive messages, pushed to GitHub, and merged into the main branch after completion.
